# RTMS — Páginas legales

Páginas estáticas con la documentación legal de la app **RTMS — Rugby Team
Manager System** (bundle ID `com.rtms.mobile`).

Servidas vía GitHub Pages en https://angelousdg.github.io/rtms-legal/.

## Contenido

- `index.html` — landing con menú a las páginas legales.
- `privacy.html` — política de privacidad (la URL pública la pide Apple
  App Store Connect y Google Play Console al subir la app).

## Cómo actualizar

Editar el HTML, commit + push a `main`. GitHub Pages re-deploya
automáticamente en 1-2 minutos. Subir la versión en el subtitle del
HTML cuando hay cambios materiales y registrar la fecha en "Última
actualización".
